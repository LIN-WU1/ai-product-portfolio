01 — COZE AGENT

AI影视导演｜分镜与 Prompt

帮助创作者完成从故事构思、剧本优化到影视分镜设计和 AI Video Prompt 生成，解决分镜设计困难、提示词不规范 与重复生成成本高等问题。

Agent
Problem
创作者有故事，却难以稳定转化为可执行的分镜与 Prompt。
Solution
通过 Story Analysis → Storyboard → Prompt 的 Agent 流程完成创作辅助。
Output
输入故事，输出人物、场景、情绪、镜头设计 与 AI Video Prompt。
Real-world Demo
故事输入 → Story Analysis → Storyboard → AI Video Prompt
案例：《东京深夜等待》

一个年轻人深夜独自站在东京街头，等待一个没有出现的人。 Agent 将创意拆解为故事核心、情绪方向、人物、 视觉元素、视觉机会与创作风险，并继续支持分镜与 Prompt 生成。

02 — DIFY WORKFLOW

AI视觉创意总监

将用户输入的故事转化为完整视觉创意方案， 通过故事分析、视觉方向设计、知识检索、 海报概念生成与图像 Prompt 生成， 形成可直接用于视觉创作的 AI Workflow。

Workflow
Input
故事、主题、视觉需求与创作限制。
Workflow
Story Analysis → Visual Direction → Knowledge Retrieval → Poster Concept → Image Prompt。
Output
结构化视觉创意方案与可继续用于生成的 Image Prompt。
Live Workflow
Story → Analysis → Visual Direction → RAG → Concept → Prompt
重点展示 Workflow 如何把一个开放式创意问题 拆成多个可控节点，而不是依赖一次性生成。

03 — COZE AGENT

DailyFlow｜工作学习助手

一个能够帮助用户整理任务、拆解计划、安排日程、 持续记忆工作习惯，并进行每日复盘的个人工作 / 学习助手。

Agent
Problem
任务分散、优先级不清，计划容易失效。
Solution
通过 Agent 对任务进行拆解、排序与计划编排， 并结合长期记忆。
Output
优先级、每日计划、提醒与复盘反馈。
Live Demo
展示用户从“把今天要做的事情告诉我” 到“得到可执行计划与复盘”的完整交互路径。
